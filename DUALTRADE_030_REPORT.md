# Three-section validation guide

Day, technical swing and fundamental investment share the native order and risk engine. See THREE_BOOKS.md for the architecture and example research limits.

Run unit tests in an isolated checkout. Native validation requires clean compilation, a separately configured Strategy Tester environment and source-bound acceptance. Compatibility-host tests are not broker execution tests. Historical logic checks do not establish profitability.

Private local session reports, account state and personal risk authorizations are intentionally excluded from the public snapshot. No historical deployment receipt grants authority to a new installation.
